# nuclo-app

A minimal [Nuclo](https://nuclo.dev) project scaffolded with `npm create nuclo`.

## Getting started

```bash
npm install
npm run dev
```

## What's inside

- `index.html` — the page; the app is drawn into `<div id="app">`
- `src/main.ts` — starts the app
- `src/app.ts` — what the page shows, built from nuclo's tag functions
- `src/styles.ts` — how it looks: your colors and fonts, and one class per element

Start with `src/app.ts`. The [docs](https://nuclo.dev/en/docs) cover the rest.

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build locally
